# MINIME — 내가 회의에 못 가도, 내 미니미는 회의에 간다

생성형 AI 기초(COE2002_01) · 4조 생성까스 텀 프로젝트

입장 카드를 근거로 불참한 나를 대신해 토론하고, **최종 결정은 사람이 하는** AI 회의 플랫폼이에요.
해커톤에서 만든 시제품을 수업 과제(계획서 · 10주차 근거 설계 · 멀티모달 보고서 · 활동 1·2 위험 점검)에 맞춰 이어 만들고 있어요.

> 발표 한 문장: **"빠진 사람의 미니미는 본인이 확인한 입장과 자료에 있는 말만 하고, 없으면 입을 다문다."**

계획서·보고서와 코드의 대응: [docs/07-수업-과제-대응표.md](docs/07-수업-과제-대응표.md)

## 1. 이렇게 써요

| 순서 | 사용자가 하는 일 | MINIME가 하는 일 |
| --- | --- | --- |
| 1 | 처음 열면 안내 카드 5장을 넘겨 봐요 | 문제 → 준비 → 대리 참석 → 침묵 → 사람의 결정 순서로 원칙을 보여 줘요 |
| 2 | 자리를 고르고 개인정보 동의를 골라요 | 항목별(필수 1 · 선택 2), 기본값은 모두 해제 |
| 3 | 내 미니미를 준비해요 (아래 5가지 중 편한 것) | 입장 카드를 만들고, 내가 확인한 것만 근거로 써요 |
| 4 | 못 가는 날엔 **자리 비움**을 켜요 | 필요할 때만 근거와 함께 말하고, 모르면 질문으로 남겨요 |
| 5 | 돌아와서 **내가 빠진 사이**를 봐요 | 미니미가 한 말을 맞아요/달라요로 확인, 보류 결정은 승인·이의 |

### 미니미를 만드는 5가지 방법

보고서를 쓰지 않는 팀원도 많아서, 문서 업로드는 그대로 두고 더 가벼운 길을 더했어요.

| 방법 | 시간 | 들어가는 것 | 근거가 되는 때 |
| --- | --- | --- | --- |
| 빠른 입장 체크 | 1분 | 쟁점마다 선택지 + 이유·조건 한 줄 | 고른 그대로 바로 (AI가 덧붙이지 않음) |
| 자료 올리기 | 3분 | txt · md · docx · pdf · pptx · hwpx | 꺼낸 글을 먼저 확인 → 입장 카드 초안 → '맞아요' |
| 단톡방에서 찾기 | 2분 | 카카오톡 내보내기 파일 | 브라우저에서 **내 말만** 골라 보냄 → 초안 → '맞아요' |
| 전달 메모 | 30초 | 그대로 전할 말 | 미니미가 고치지 않고 회의마다 한 번 전함 |
| 지난 미니미 | 30초 | 다른 회의방에서 내보낸 파일 | 자료는 그대로, 입장 카드는 초안으로 다시 확인 |

빈 쟁점은 **3분 인터뷰**가 짧게 물어보고(말로 답해도 돼요), 회의가 끝나면 내 발언에서 바뀐 입장 후보를 찾아 줘요(동의한 경우).

## 2. 빠른 시작

```bash
./run.sh            # macOS / Linux   (Windows: run.bat 더블클릭)
```

처음 실행하면 가상환경을 만들고 패키지를 설치한 뒤 `http://localhost:8000` 을 띄워요.
**모델이 없어도 동작해요.** 이때 엔진 표시는 `규칙 대체`이고, 미니미는 입장 카드와 자료 문장을 그대로 인용해요.

- 시연 방: `http://localhost:8000/?room=demo` → 위쪽 **[▶ 시연]** 으로 장면 실행 (등장인물 민준·지연·하린·도윤은 모두 가상 인물)
- 여러 명이 접속: 서버 로그의 `팀원 접속 주소`를 같은 와이파이에서 열거나, 회의방의 QR 아이콘
- 이용 안내 카드 다시 보기: `?guide=1` 또는 메뉴 › 이용 안내

### 모델 (로컬 → API → 규칙)

`.env`의 `LLM_ORDER` 순서대로 시도하고 실패하면 다음으로 넘어가요. 마지막엔 항상 규칙 대체가 있어 회의가 멈추지 않아요.

```bash
ollama pull qwen3.5:4b && ollama pull qwen3.5:9b && ollama pull bge-m3   # 로컬 (기본)
# 또는 .env:  LLM_ORDER=api  /  API_KEY=sk-...                            # API
```

근거 검증(NLI)은 시연 전에 꼭 설치해 주세요. 없으면 핵심어 검사로 대신하고, 엔진 표시에 **근거 검증 약함** 경고가 떠요.

```bash
pip install torch --index-url https://download.pytorch.org/whl/cpu && pip install -r requirements-ml.txt
```

## 3. 원칙과 안전장치

| 원칙 | 어떻게 지키나 | 코드 |
| --- | --- | --- |
| 근거가 있을 때만 말한다 | 문장마다 출처, 출처가 내용을 뒷받침하는지 NLI로 검사, 근거 점수가 낮으면 침묵 | `persona.compose` · `nli.py` |
| 조건부 입장을 바꾸지 않는다 | 입장 카드의 양보 불가 조건이 발언에서 빠지면 그대로 덧붙임 | `persona.keep_red_line` |
| 모르는 건 지어내지 않는다 | "본인에게 확인이 필요해요" + 돌아오면 볼 질문으로 저장 | `persona.abstain_text` |
| 결정은 사람이 한다 | 불참자 관련 결정은 보류, 참석자 이견도 결정·회의록에 남김 | `minutes.record` · `minutes.dissenters` |
| 본인이 확인한다 | 돌아와서 미니미 발언마다 맞아요/달라요 → 발언 수정률 | `orchestrator.review_message` |
| 개인정보 | 항목별 동의(기본 해제), 동의 전 발언·대리 참석 차단, 30일 보유 후 자동 삭제, 내 기억 삭제 | `main.set_consent` · `store.purge_older_than` |

AI 발언은 항상 **'○○ 미니미' 라벨 + 점선 말풍선**으로 구분돼요. 전달 메모는 왼쪽 굵은 선, 본인이 정정한 말은 빨간 메모로 보여요.

## 4. 평가와 테스트

```bash
python -m pytest -q          # 규칙·시나리오·4인 접속·엔진 대체·수업 기능(동의·빠른 입장·메모·채팅·이견·본인 확인)
python eval/eval.py --sweep  # 지표 6개 + 침묵 임계값 스윕 → eval/results/latest.md
```

계획서 07 종료 기준(일치율 90% · 발언 수정률 15% 이하 · 사실 오류 0건) 중 **발언 수정률**은 실제 사용에서 쌓여요.
회의록 창과 `GET /api/rooms/{방}/review` 에서 확인할 수 있어요. `eval.py` 수치는 작은 시드 세트(질문 36 · 라벨 28 · 주장 22) 기준이라 경향만 보여 줘요.
