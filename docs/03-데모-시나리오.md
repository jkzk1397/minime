# MyMini 데모 가이드

데모는 두 가지입니다. 발표장 상황에 맞게 고르세요.

| | A. 발표용 데모 (`demo-v1.html`) | B. 실제 서버 데모 (`app/`) |
|---|---|---|
| 필요한 것 | 브라우저만 | Python, (선택) OpenAI 키 |
| 특징 | 시나리오가 자동 재생되어 **실패하지 않음** | 진짜 LLM이 실시간으로 대답함 |
| 추천 상황 | 본 발표 | 질의응답, "진짜 돌아가요?" 질문 |

---

## A. 발표용 데모 실행

`demo-v1.html`을 더블클릭해서 브라우저로 엽니다. 끝입니다.

- **데모 재생**을 누르면 자동으로 진행되고, **다음 장면**으로 한 장면씩 넘길 수도 있습니다. 속도는 느리게/보통/빠르게로 조절합니다.
- 위쪽 단계 표시줄에서 지금 어느 장면인지 보입니다.
- 왼쪽: 사람 3명 + 미니미 3명, 자리 비움 버튼
- 가운데: 채팅방
- 오른쪽: 오케스트레이터 점수 패널(누가 왜 말하는지) + 활동 로그

---

## B. 실제 서버 데모 실행

```bash
cd mymini-backend
python -m venv .venv
.venv\Scripts\activate          # Windows  (Mac/Linux: source .venv/bin/activate)
pip install -r requirements.txt
copy .env.example .env          # Mac/Linux: cp .env.example .env
#   .env에 OPENAI_API_KEY를 넣으면 진짜 LLM, 비우면 MOCK 모드
uvicorn app.main:app --reload --port 8000
```

브라우저 탭 3개로 `http://localhost:8000` 을 열고 각각 **종원 / 민수 / 지현**으로 입장합니다.
`http://localhost:8000/health` 에서 지금 `mock`인지 `openai`인지 확인할 수 있습니다.

## 발표 시나리오 (약 3분)

| # | 장면 | 할 일 | 말할 멘트 |
|---|---|---|---|

| 3 | AI 반응 | 오른쪽 점수 패널을 가리키기 | "모든 AI가 떠들지 않습니다. 진행자 AI가 관련 있는 미니미만 골라 말하게 합니다." |

| 7 | AI끼리 회의 | 미니미들이 주고받는 장면 | "사람이 아무것도 안 해도 AI끼리 회의가 이어집니다." |
| 8 | 자료조사 | 🔍 검색 결과 카드 | "확인이 필요한 건 직접 찾아보고 결과를 공유합니다." |
| 9 | 회의 종료 | (서버 데모) '회의 종료·정리' 버튼 | "안건, 주요 의견, 충돌, 결론이 자동으로 정리됩니다." |
| 10 | 민수 복귀 | 자리 비움 OFF → 부재 중 요약 | "민수는 돌아와서 이 요약만 보고 '그대로 가자' 하면 됩니다." |
| 11 | 마무리 | - | **"내가 회의에 못 가도, 내 미니미는 회의에 간다."** |

## 예상 질문과 답변

**Q. AI가 내 의견을 멋대로 말하면요?**
A. 미니미는 주인이 예전에 한 말을 근거로만 말하고, 근거 없는 약속은 하지 않도록 지시되어 있습니다. 최종 결정은 사람이 하고, 돌아오면 미니미가 대신 한 말을 요약에서 따로 확인할 수 있습니다. 다음 단계에서는 "의견 전달만" / "동의까지" 같은 대리 권한 설정을 넣을 계획입니다.

**Q. AI끼리 끝없이 떠들지 않나요?**
A. 사람 메시지 하나당 최대 4턴이고, 턴이 지날수록 말하기 위한 기준 점수가 올라갑니다. 같은 미니미가 연달아 말할 수도 없습니다.

**Q. 기존 회의 AI랑 뭐가 달라요?**
A. 기존 도구는 "기획 AI", "개발 AI"처럼 역할 중심입니다. MyMini는 "민수 AI"처럼 실제 사람을 대변합니다. Role-based에서 Person-based로 바뀐 겁니다.

**Q. 말투는 어떻게 학습시키나요?**
A. 지금은 말투와 성향을 직접 입력하고, 대화할수록 발언이 기억에 쌓입니다. 다음 단계에서는 과거 채팅이나 문서를 올리면 자동으로 뽑아내도록 할 계획입니다.
