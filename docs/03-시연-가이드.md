# MyMini 시연 가이드 (v3)

시연은 회의방 위쪽의 **[▶ 시연]** 버튼으로 합니다. 장면마다 대사(입력)만 대본이고, 미니미의 판단·발언·검증·회의록은 **실제 모듈이 그 자리에서** 만듭니다.
모든 접속자 화면이 같이 움직이므로, 참가자 4명이 휴대폰으로 들어와 있으면 각자 화면에서도 같은 장면이 보입니다.

## 준비 (시작 30분 전)

- [ ] 발표 노트북에서 `run.bat`(Windows) / `./run.sh`(Mac) 실행 → 로그의 **팀원 접속 주소** 확인
- [ ] 노트북과 참가자 기기를 같은 와이파이(불안하면 **휴대폰 핫스팟**)에 연결, Windows 방화벽 '허용'
- [ ] 빔 화면: 로비 → **발표 화면으로 보기** → 왼쪽 안건·멤버 / 가운데 대화. '미니미의 머릿속'은 미니미 말풍선을 누르거나 위쪽 패널 아이콘으로 열림 (시연 중 판단·근거 장면에서는 발표 화면에서 자동으로 열림)
- [ ] 참가자 4명: 위쪽 QR 아이콘(팀원 초대) → QR 스캔 → 종원·민수·지현·하은 자리 선택 (민수 역할은 휴대폰이면 복귀 화면이 잘 보임)
- [ ] 엔진 확인: 회의방 제목 아래 엔진 표시가 `로컬 · qwen3.5:9b`(초록) / `API`(파랑) / `규칙 대체`(주황). 와이파이가 불안하면 `.env`의 `LLM_ORDER=rule`로 고정해도 시연은 그대로 됩니다
- [ ] [▶ 시연] → **처음부터**(↻) 한 번 끝까지 리허설 (속도 '빠르게'로 2분) → 다시 **처음부터**
- [ ] 백업: 리허설을 화면 녹화해 둔다

## 진행 (약 3분 + 질의응답)

| # | 장면 (버튼) | 발표 멘트 | 화면에서 가리킬 곳 |
| --- | --- | --- | --- |
| 0 | 팀과 안건 | "'스피치와 토론' 4조. 오늘 회의엔 2명이 수업 때문에 못 옵니다. 원래라면 회의가 미뤄지죠." | 왼쪽 안건·쟁점 3개 |
| 1 | 준비: 민수의 미니미 | "민수가 회의 전에 보고서를 올리면 입장 카드 초안이 생기고, AI는 **빈 쟁점만** 묻습니다. 한 줄로 대충 답해도 미니미가 풀어 쓰고, 본인이 '맞아요'를 누른 것만 근거가 됩니다." | 민수 화면 미리보기: 보고서 → 인터뷰 → 준비도 1/3 → 3/3 |
| 2 | 대리 참석 | "민수와 하은이 빠졌습니다. 종원이 상호작용형으로 바꾸고 A안을 꺼내자 **민수의 미니미가 반론**하고, **하은의 미니미가 바로 이어** 조건을 붙입니다. 주인 색의 점선 말풍선이 미니미입니다. 문장마다 출처 칩이 있고, 말풍선을 누르면 **왜 지금 말했는지** 점수가 보입니다. 개입형이면 가장 관련 있는 1명만 말합니다." | 출처 칩 클릭(원문 팝업), 미니미 말풍선 클릭(개입 판단 막대) |
| 3 | 침묵 | "보고서에 없는 걸 물으면 지어내지 않습니다. '민수 님께 확인이 필요해요' — 그리고 돌아오면 볼 질문으로 남깁니다. 날짜를 정해 달라는 **약속**도 위임 범위 밖이라 보류합니다." | 근거 탭: 점수가 임계값 아래 |
| 4 | 흐름 유지 | "잡담이 이어지면 안건 거리 그래프가 치솟고, 두 번 연속이면 회의 도우미가 남은 쟁점을 꺼냅니다. 이 판단엔 LLM이 필요 없습니다." | 안건 거리 그래프 |
| 5 | 2차 검증과 보류 결정 | "지현이 결론을 내리자 불참자에게 영향을 주는 결정이라 **자동 보류**됩니다. 지현이 자기 미니미에게 검증을 맡기면 — 근거 약함, **지난 회의 발언과 충돌**, 하은의 양보 불가 조건을 놓침, 반대 관점까지. 고칠지는 사람이 정합니다." | 검증 카드 |
| 6 | 모델이 꺼져도 계속 | "지금 모델을 끕니다. 엔진이 '규칙 대체'로 바뀌어도 하은의 미니미는 보고서 문장을 인용해 답합니다." | 제목 아래 엔진 표시, 엔진 탭 |
| 7 | 회의 종료 | "쟁점마다 누가 무슨 의견을 냈는지, 충돌과 결정 상태가 정리됩니다." | 회의록 카드, 내보내기 |
| 8 | 복귀 | "돌아온 민수는 '내가 빠진 사이'에서 미니미가 한 말을 확인하고, 예산안은 승인, 역할 분담엔 이의를 답니다. 남긴 질문에 답하면 다음 회의부터는 미니미가 답할 수 있습니다." | 민수 화면 미리보기 (휴대폰이면 실물) |

마무리: **"빠진 사람의 미니미는 본인이 확인한 입장과 보고서에 있는 말만 하고, 없으면 입을 다문다."** → 평가 결과 표(README 6장 또는 `eval/results/latest.md`).

## 장애 대응

| 상황 | 대응 |
| --- | --- |
| 모델이 느림/죽음 | 그대로 진행 (자동 규칙 대체). 또는 엔진 탭 '모델 끄기' |
| 참가자 기기가 접속 안 됨 | 같은 와이파이인지, 주소가 `localhost`가 아닌 노트북 IP인지, 방화벽 허용했는지 확인. 안 되면 관전 화면 하나로 시연 |
| 장면이 꼬임 | [▶ 시연] → **처음부터**(↻) (방을 시연 시작 상태로 되돌림) |
| 화면이 멈춘 듯함 | 상단 '연결이 끊겼어요' 배너면 자동 재접속 중. 새로고침해도 자리는 유지 |

## 예상 질문

**Q. 미니미가 내 생각을 멋대로 지어내면요?**
A. 본인이 '맞아요'를 누른 입장 카드와 보고서 문단만 근거로 씁니다. 문장마다 출처를 달고, 생성 후 검사에서 출처가 뒷받침하지 않는 문장은 지웁니다(평가: 근거 일치율). 근거 점수가 낮으면 아예 말하지 않습니다(올바른 침묵률 93.8%).

**Q. 그럼 결정은 누가 하나요?**
A. 사람입니다. 불참자 입장에 영향을 주는 결정은 자동 보류되고, 돌아온 사람이 승인해야 확정됩니다. 약속(날짜·역할·비용)은 미니미가 대신하지 않습니다.

**Q. AI를 '학습'시키나요?**
A. 모델은 훈련하지 않습니다. 보고서·확인된 입장·회의 기억을 쌓고 검색하는 방식이라 첫 회의부터 동작합니다. '고칠래요'로 고친 문장 같은 데이터는 나중에 파인튜닝 데이터로 쓸 수 있게 모아 둡니다.

**Q. 왜 모든 미니미가 떠들지 않나요?**
A. 개입 게이트가 관련도·근거·새로움·입장 차이에서 끼어들기 비용을 뺀 점수로 정하고, 애매할 때만 작은 모델에게 묻습니다. 사람 발언 하나당 최대 1명(상호작용형은 2명)이고, 미니미끼리 주고받는 루프는 없습니다.

**Q. 개인정보는요?**
A. 판단 기준·관련 경험처럼 안건 판단에 쓰이는 것만 받고, 학번·연락처·성향검사 같은 신상은 받지 않습니다. 로컬 모델이면 보고서가 노트북 밖으로 나가지 않고, '내 기억 삭제'로 언제든 지웁니다.

**Q. 기존 회의록 도구와 뭐가 달라요?**
A. 회의록 도구는 끝난 뒤 정리합니다. MyMini는 빠진 사람의 입장을 회의 *중에* 근거와 함께 전하고, 그 사람에게 결정을 돌려줍니다.
