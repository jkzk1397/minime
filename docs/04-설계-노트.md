# MyMini 설계 노트 — 학습 · 입력 · 페르소나 · 정합성

> 기획서 v3(`PROJECT_OVERVIEW_v3.md`)를 구현하면서 팀이 던진 질문 4개에 대한 답이다.
> 각 질문마다 **① 기획서에 이미 있는 것 → ② 비어 있던 것 → ③ 구현에서 이렇게 풀었다 → ④ 다음 단계** 순서로 쓴다.

---

## 0. 전제: MyMini의 '개인화'는 파인튜닝이 아니다

**LLM + Memory + Persona + RAG + Prompt Context + Feedback → 개인화된 에이전트.** 모델 가중치는 바꾸지 않는다.

| 구성 | 역할 | MyMini 구현 |
| --- | --- | --- |
| Base LLM | 언어 이해·추론 | 빠른 레인 `qwen3.5:4b`(개입 판단) + 생각 레인 `qwen3.5:9b`(발언·검증·회의록). 실패하면 OpenAI 호환 API → 규칙 대체 (`app/llm.py`) |
| Personal Memory | 사용자의 과거 정보 | 보고서 문단, 지난 회의 발언, 회의 중 본인 발언, 복귀 후 답한 질문, 회의 후 '추정' 기억 (`Persona.reports/past/questions`, `persona.infer_memory`) |
| Persona | 선호·의사결정 기준 | 판단 기준(우선순위) · 관심 분야 · 관련 경험 · 말투 예시 + **입장 카드** + 위임 범위 (`models.Profile/Stance/Scope`) |
| RAG | 필요한 과거 정보 검색 | Kiwi BM25 + 벡터(bge-m3) → RRF, 근거 점수로 침묵 결정 (`app/retrieval.py`) |
| Prompt Context | 현재 회의에 필요한 정보 주입 | 안건·현재 쟁점·최근 대화·검색 근거·판단 기준·위임 범위, 비슷한 상황의 라벨 예시 3개 (`prompts/*.md`, `gate.pick_examples`) |
| Feedback | Persona 업데이트 | 인터뷰 '맞아요/고칠래요', 입장 카드 대체, 보류 결정 승인·이의, 남긴 질문에 답 → 확인된 입장 (`interview.confirm`, `minutes.respond`, `orchestrator.answer_question`) |

그래서 '학습'은 세 가지 뜻으로만 쓴다: **검색할 근거를 쌓는 것(Memory·RAG)**, **본인이 확인한 입장을 늘리는 것(Persona·Feedback)**, **사람 라벨 예시를 늘리는 것(Prompt Context)**. 모두 훈련 없이 회의 1번째부터 동작한다.

## 1. AI가 사람의 '생각 흐름·논리 구조'를 어떻게 배우나

**① 기획서에 있는 것**: 입장 카드 필드(주장 / 근거(문단 id) / 우선순위 / 양보 불가선 / 모르는 영역), 인터뷰가 '판단 기준'을 잡는다는 표(4장), M3에서 Toulmin으로 *남의* 발언을 검증. 파인튜닝은 로드맵.

**② 비어 있던 것**: 그 사람이 근거에서 결론까지 *어떻게* 가는지(어떤 기준을 먼저 보는지, 근거와 주장을 잇는 전제가 무엇인지)를 저장하는 구조. 그리고 그 구조를 발언할 때 어떻게 쓰는지.

**③ 구현**: 생각 흐름 = **판단 기준(순서) + Toulmin 입장 카드**로 표현한다.

| 사람의 생각 | 저장 위치 | 발언에 쓰이는 방식 |
| --- | --- | --- |
| 무엇을 먼저 보나 | `Profile.criteria` 1~3순위 (예: 민수 = 학생 만족도 데이터 → 비용 대비 효과 → 근거의 출처) | 발언 프롬프트에 우선순위대로 주입 → 모델이 그 순서로 논증 |
| 무엇을 주장하나 | `Stance.claim` + `position`(선택지) | 게이트가 상대 발언의 선택지와 비교해 '입장 차이'를 계산 → 반론/동의+조건 결정 |
| 무엇을 근거로 | `Stance.reasons` + `sources`(보고서 문단) | 출처 칩으로 인용 |
| 근거가 왜 주장을 뒷받침하나 | `Stance.warrant` (판단 기준과 같은 층위) | 프롬프트에 함께 넣고, 2차 검증의 Toulmin '전제' 칸과 같은 구조 |
| 어디까지 양보하나 | `Stance.red_line` | 같은 편 결론이 나와도 조건이 빠지면 '동의 + 조건'으로 끼어듦, 검증 카드의 '놓친 점' |
| 모르는 것 | `Stance.unknown` | 근거 점수가 낮으면 침묵 + 복귀 후 질문 |

같은 Toulmin 구조를 **내 생각을 저장할 때(입장 카드)** 와 **남의 말을 검증할 때(M3)** 둘 다 쓰기 때문에, "지난주 발언과 충돌" 같은 판정이 구조적으로(선택지 대 선택지) 가능하다.

'배우는' 과정(훈련 없음):
1. 보고서 → 입장 카드 **초안**(모델 또는 규칙 추출) → 2. 빈 쟁점만 인터뷰 → 3. 본인 확인한 카드만 근거
4. 회의 중 본인 발언 → 회의 끝에 '추정' 카드 → 본인 확인 시 '확인됨' (Generative Agents의 기억·회고)
5. 미니미가 답 못 한 질문 → 복귀 후 답 → 확인된 입장 (다음 회의부터 답할 수 있다)

**④ 다음 단계**: '고칠래요'로 고친 문장은 (AI 초안 → 본인 수정) 쌍이라 **그대로 선호 학습(DPO) 데이터**가 된다. 게이트 라벨, 보류 결정 승인·이의도 쌓이면 LoRA(Unsloth + Colab 무료 GPU)로 작은 모델을 미세조정한다. 지금은 수집 구조만 갖췄다.

## 2. 처음에 무엇을 어떻게 입력받나 — 보고서 먼저? 학습 먼저?

**① 기획서에 있는 것**: 5가지 방식 비교 후 **보고서 + 안건별 3분 입장 인터뷰** 채택, AI 확장은 본인 확인 조건부, 준비도 계산(4장, M6).

**② 비어 있던 것**: 실제 온보딩 순서, 보고서가 없을 때, 보고서를 어떤 모양으로 쓰게 할지.

**③ 구현 — 결론: "각자 짧은 보고서 먼저 → AI는 빈 곳만 인터뷰"**. '학습'은 따로 없다(넣는 즉시 검색·인용 가능).

| 단계 | 시간 | 화면 | 하는 일 |
| --- | --- | --- | --- |
| ① 프로필 | 1분 | 내 미니미 준비 › 프로필 | 역할·판단 기준·관심 키워드·말투 예시·위임 범위·동의 |
| ② 보고서 | 붙여넣기 | › 보고서 | 문단으로 나눔 → 입장 카드 **초안** 자동 생성 → 준비도에 '보고서 근거'로 반영 |
| ③ 인터뷰 | 약 3분 | › 입장 인터뷰 | 확인된 입장이 없는 쟁점만 최대 5문항: 초안 확인("보고서를 보면 ~로 읽혀요. 맞나요?") / 선택지 질문 / 열린 질문 / 양보 불가선 |
| ④ 확인 | 클릭 | 맞아요 · 고칠래요 · 아니에요 | 확인된 문장만 근거. 같은 쟁점의 예전 카드는 자동 대체 |
| ⑤ 준비도 | - | › 준비도·대리 참석 | 쟁점별 상태(확인된 입장 / 보고서 근거 / 초안만 / 근거 없음) → 낮으면 대리 참석 켤 때 경고 |

왜 보고서가 먼저인가:
- 팀플은 원래 "각자 조사 → 공유" 순서라 사용자 부담이 거의 0이다 (이미 쓴 글).
- 보고서가 있으면 인터뷰가 '처음부터 묻기'가 아니라 '초안 확인'이 돼서 짧아진다 (시연 1장면: 1/3 → 3/3).
- 사실(숫자·사례)은 보고서에서, 입장(선호·양보 불가선)은 인터뷰에서 — 둘이 서로 다른 빈칸을 채운다.

보고서가 없으면: 인터뷰만으로도 모든 쟁점을 채울 수 있다(확인된 입장 = 준비도 충족). 다만 인용할 사실이 없어 발언이 짧아진다.

권장 보고서 모양 (문단 4~6개, 빈 줄로 구분 — 문단 단위로 `[보고서 n문단]` 인용됨):
1. 조사한 사실 1 (숫자와 출처)
2. 조사한 사실 2 / 사례
3. 그래서 내 입장: "나는 ___이 좋다고 생각한다. 이유는 ___."
4. 조건: "다만 ___은 양보할 수 없다."
5. 아직 모르는 것

**④ 다음 단계**: 인터뷰 질문을 모델이 상황에 맞게 다듬기(지금은 빈 쟁점 감지 + 규칙 문장), 카톡·과거 회의록 가져오기(본인 발언만, 동의 절차).

## 3. 페르소나에 무엇을 적나 — 프로젝트·약력·개인 신상의 선

**① 기획서에 있는 것**: 성향 설문(MBTI·Big Five) 제외, 말투는 예시 문장 2~3개, 위임 범위, 동의·삭제.

**② 비어 있던 것**: 프로젝트·약력·개인 신상을 어디까지 받을지의 기준.

**③ 구현 — 기준은 하나: "이 정보가 안건에 대한 그 사람의 발언을 바꾸거나, 미니미가 할 수 있는 일을 제한하는가?"**
아니면 받지 않는다 (개인정보 보호법의 최소 수집 원칙과도 같다).

| 구분 | 항목 | 쓰이는 곳 |
| --- | --- | --- |
| 필수 | 이름, 팀에서 맡은 일, **위임 범위**(의견만 / 질문 답변까지 + 약속 금지 항목), 동의 2개(보고서 사용 · 발언 기억) | 표시, 약속 요청 시 보류, 저장 여부 |
| 권장 | **판단 기준 1~3순위**, 관심·전문 키워드, 말투 예시 2~3문장 | 생각 흐름, 게이트 관련도, 말투 |
| 선택 | 관련 경험·프로젝트 1~3줄 (**이번 안건과 관련된 것만**) | `[약력 n]`으로 인용되는 근거 → 사실이어야 함 |
| 받지 않음 | 학번·연락처·주소·사진, 나이·성별·출신, MBTI·성격검사, 성적, 건강·종교·정치 성향, 다른 사람의 개인정보 | - |

받지 않는 이유: 안건 의견을 예측하는 힘이 약하고 고정관념만 만든다. 인터뷰 기반 에이전트가 인구통계 기반 에이전트보다 응답을 더 잘 재현하고 집단 간 편향도 적었다는 결과(Park 외 2024, Generative Agent Simulations of 1,000 People)가 근거다.
화면(내 미니미 준비 › 프로필)에 "적어 주세요 / 적지 않아요" 안내를 그대로 넣었고, '내 기억 삭제'로 보고서·입장·질문을 한 번에 지울 수 있다.

**④ 다음 단계**: 위임 범위를 쟁점별로(예: 예산은 의견만, 역할은 답변까지), 프로필 항목을 팀이 수업별 템플릿으로 저장.

## 4. 정합성은 어떻게 검증하나

**① 기획서에 있는 것**: M1 출처 강제 + 생성 후 출처 검사, 근거 점수로 침묵, M3(주장 분해 → Toulmin → 검증 질문 → 판정 카드 + 반대 관점), 평가 지표(근거 일치율·올바른 침묵률·검증 탐지율·페르소나 충실도).

**② 비어 있던 것**: 페르소나 자체의 정합성(입장 카드끼리 모순), 숫자 정합성, 미니미가 한 말을 본인이 사후에 바로잡는 고리.

**③ 구현 — 4겹**

| 층 | 무엇을 맞추나 | 방법 | 코드 |
| --- | --- | --- | --- |
| 1. 입력 | 페르소나 ↔ 본인 | AI가 만든 문장은 '초안'. 본인이 확인한 것만 근거. 같은 쟁점에 다른 선택지를 확인하면 예전 카드 자동 대체 + 알림 | `interview.confirm` |
| 2. 생성 | 미니미 발언 ↔ 근거 | 문장마다 출처 라벨 필수 → 생성 후 핵심어 일치 검사로 뒷받침 안 되는 문장 삭제(삭제 수 표시). 근거 점수 < 0.35면 침묵. 약속 요청은 위임 범위 밖이라 보류 | `persona.check_citations`, `gate.evaluate` |
| 3. 발언 | 사람 발언 ↔ 자료·과거 | 원자 주장 → Toulmin(근거·전제·단정 표현) → 내 자료/이전 발언/팀원 자료를 따로 검색 → **선택지 충돌**(지난 발언·내 입장 카드) · **수치 대조**(같은 대상·단위 숫자 불일치: "응답자 2천 명" ↔ "812명") · **단정 표현**(항상·전부·확실) · 팀원의 양보 불가선을 놓쳤는지 · 반대 관점(다른 선택지를 확인한 팀원의 입장과 근거) | `verify.py` |
| 4. 사후 | 미니미 ↔ 본인 / 시스템 ↔ 지표 | 복귀자의 '내가 빠진 사이'에서 미니미 발언 확인, 보류 결정 승인·이의, 남긴 질문에 답 → 확인된 입장. 평가 스크립트로 지표 측정 | `minutes.digest`, `eval/eval.py` |

규칙 대체 기준선 결과(시드 세트): 근거 일치율 100%, 올바른 침묵 93.8% / 잘못된 침묵 10%, 검증 탐지 100% / 오탐 0%, 입장 일치 100%. 숫자 불일치·'전부' 같은 사례는 평가에서 처음엔 놓쳤고, 수치 대조와 단정 표현 목록을 추가해 잡았다(`eval/data/claims.jsonl`의 '어려운 사례').

**④ 다음 단계**: 핵심어 일치 대신 한국어 NLI(KLUE-NLI 계열)로 함의 판정, LLM 심판(위치 바꿔 2회), 미니미 발언에 본인이 '내가 할 말인가 1~5점'을 매기는 버튼(페르소나 충실도 실측).

## 5. 기획서 대비 구현 현황 (Z.3 표 갱신)

| 기능 | 기획서 v3 | 구현 |
| --- | --- | --- |
| 대리 참석 ON/OFF + 위임 범위 | 할 일 | ✅ 준비도 경고, 위임 범위(의견만/답변까지 + 약속 금지) |
| 부재 중 요약 + 보류 결정 | 할 일 | ✅ '내가 빠진 사이' 모달, 승인·이의, 남긴 질문 답 |

| 회의록 | 쟁점별 + 결정 상태 | ✅ 확정/보류/확인 필요/이의, .md 내보내기 |
