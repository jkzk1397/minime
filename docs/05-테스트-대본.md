# 4명 실사용 테스트 대본 (약 20분)

위에서부터 순서대로, 각자 자기 차례에 적힌 말을 그대로 보내면 됩니다. 라운드마다 기능이 하나씩 늘어나요.
`인용` 칸은 입력창에 보낼 말, **[버튼]** 은 화면에서 누를 버튼입니다.

| 사람 | 역할 | 기기 | 테스트에서 |
| --- | --- | --- | --- |
| 종원 | 사회 | 노트북(서버) | 자리에 있음 |
| 정민 | 발표 | 휴대폰 | 자리에 있음 |
| 혜중 | 자료조사 | 휴대폰 | 미니미를 만들고 빠짐 |
| 동준 | 반론 | 휴대폰 | 이미 준비된 미니미로 빠짐 |

## 핵심 기능 6가지

| 기능 | 한 줄 설명 | 확인 라운드 |
| --- | --- | --- |
| 미니미 준비 | 보고서와 한 줄 인터뷰로 입장 카드를 만들고, '맞아요'를 누른 것만 근거로 씀 | 2 |
| 대신 참석 | 자리 비움을 켜면 미니미가 점선 말풍선으로 대신 말함. 관련 있고 근거가 있을 때만 | 3·4 |
| 근거와 침묵 | 근거 있는 문장엔 밑줄(누르면 원문). 근거가 없으면 '확인 필요', 약속은 '보류' → 질문으로 남김 | 4·5 |
| 회의 도우미 | 대화가 두 번 연속 안건을 벗어나면 남은 쟁점을 알려 줌 | 6 |
| 결정과 2차 검증 | 결론을 자동 기록, 빠진 사람과 관련되면 보류. 내 말을 내 미니미가 근거·지난 발언·놓친 조건으로 점검 | 7 |
| 돌아오기와 회의록 | 쟁점별 회의록, 돌아온 사람에게 '내가 빠진 사이' 요약 + 승인·이의·질문 답 | 9·10 |

## 0. 방 만들고 들어오기 (3분)

- **종원**: 노트북에서 `run.bat` → 로비 **[새 회의방 만들기]** → 방 코드 `test1`, **[시연용 시나리오로 채우기]** 체크 → **[방 만들기]** → 자리 **[종원]**
- **종원**: 위쪽 QR 아이콘 **[팀원 초대]** 를 화면에 띄우기
- **혜중·정민·동준**: 같은 와이파이에서 QR 찍기 → 자기 이름 자리 누르기
- 성공: 멤버 목록(휴대폰은 아래 **[참석자]**)에 4명 모두 초록 점

## 1. 그냥 채팅 (1분)

- **종원**: `다들 들어왔지? 오늘은 축제 예산안부터 정해 보자.`
- **정민**: `좋아. 나는 발표 자료 쪽을 맡을게.`
- 성공: '회의를 시작했어요' 안내, 내 말은 오른쪽, 사람마다 테두리 색이 다름

## 2. 미니미 만들기 (3분) — 혜중

- **혜중**: 아래 **[내 미니미]** → ② **[보고서]** → **[예시 보고서 넣기]** → **[올리고 입장 카드 초안 만들기]**
- **혜중**: ③ 인터뷰 **[빈 곳만 질문 받기]** → 질문마다 **[예시 답 넣기]** → **[답하기]** → **[맞아요]** (3번)
- 성공: ⑤ 준비도 **3/3** (동준은 처음부터 준비돼 있음)

## 3. 자리 비우기 (1분) — 혜중·동준

- **혜중·동준**: 아래 **[참석자]** → 맨 아래 **[자리 비움]** 켜기
- 성공: "○○ 님이 불참해요. 미니미가 대리 참석합니다." 아바타가 점선, 입력창 자리에 **[돌아왔어요]**. 이제 둘은 지켜보기만

## 4. 미니미가 대신 말하기 (2분)

- **종원**: 오른쪽 위 **[⋯]** → **[상호작용형]** (미니미가 최대 2명까지 이어서 말함)
- **종원**: `나는 공연이 축제의 얼굴이라 A안이 현실적이라고 봐.`
- **모두**: 밑줄 친 문장 눌러 보기(원문), 미니미 말풍선 눌러 보기(왜 말했는지 점수)
- **정민**: `오 둘 다 데이터가 있으니까 설득력 있네.`
- 성공: 동준 미니미가 반론 → 혜중 미니미가 "동준 님 미니미 말에 덧붙이면…"으로 이어서 말함

## 5. 모르면 말 안 하기 (2분)

- **정민**: `혜중 미니미, 무대 음향 장비 대여 업체는 알아봤어?`
- **종원**: `동준아 리허설 날짜는 네가 정해 줄 수 있지? 목요일 어때?`
- 성공: 혜중 미니미 **확인 필요**, 동준 미니미 **약속 보류** — 둘 다 돌아오면 볼 질문으로 남김

## 6. 딴 얘기하기 (1분)

- **종원**: `근데 어제 축구 봤어? 손흥민 골 미쳤던데`
- **정민**: `ㅋㅋ 봤지. 오늘 점심 학식 뭐 나와?`
- 성공: **회의 도우미**가 남은 쟁점 3개를 알려 줌

## 7. 결정과 2차 검증 (3분)

- **정민**: `결론적으로 B안으로 가자. 학생 참여 프로그램이 만족도가 항상 더 높으니까 확실해.`
- **정민**: 방금 보낸 내 말풍선을 한 번 누르기 → **[2차 검증]** (노트북은 마우스를 올리면 나옴)
- **종원**: `좋아. 발표 역할은 내가 사회랑 도입, 정민이가 본론, 혜중이가 질의응답 근거 정리하는 걸로 하자.`
- 성공: **결정 보류** 2개(혜중·동준 확인 전). 정민 미니미가 '지난 회의엔 A안 · 항상·확실은 근거보다 강함 · 동준의 조건을 놓침 · 반대 관점'을 알려 줌

## 8. 이름 불러 묻기 (1분)

- **종원**: `동준 미니미, 타 대학 사례는 어떤 게 있어?`
- 성공: 동준 미니미가 보고서를 근거로 답함 (공연 1팀으로 줄이고도 방문객 15% 증가)

## 9. 회의 끝내기 (1분)

- **종원**: **[⋯]** → **[회의 종료 · 회의록]** → **[끝내고 정리]** → 도우미 말풍선의 **[회의록 보기]**
- 성공: 쟁점별 의견·충돌·결정 상태(보류)

## 10. 돌아오기 (3분) — 혜중·동준

- **혜중·동준**: **[돌아왔어요]** → '내가 빠진 사이'
- **혜중·동준**: 'B안으로 가자'는 **[승인]**, '발표 역할…'은 이유를 쓰고 **[이의]** (예: `질의응답은 좋은데 설문 결과 슬라이드는 제가 직접 발표하고 싶어요.`)
- **혜중·동준**: 남은 질문에 한 줄로 답하고 **[답하기]**
- 성공: 둘 다 승인하면 'B안으로 가자' **확정**, 역할 결정은 **이의**. 답한 내용은 다음 회의부터 미니미가 근거로 씀

## 더 해 보기

- **정민·종원**: **[내 미니미]** 에서 준비도 2/3 → 인터뷰로 빈 쟁점에 한 줄 답 → 3/3
- **누구나**: 입력창 왼쪽 요술봉 → 한 줄만 쓰기 → 미니미가 다듬어 줌 → **[이대로 보내기]**
- **종원**: **[⋯]** → **[호출형]**: 이제 "@혜중"처럼 불러야만 미니미가 말함

## 자유롭게 대화해 볼 때

- 미니미는 **자리 비움**을 켠 사람 것만 말해요.
- 쟁점과 관련된 말에, 미니미 주인의 입장과 다른 의견일 때 잘 끼어들어요 (A안/B안, 설문/사례, 역할 분담).
- 바로 물어보려면 "○○ 미니미, …?" 또는 "@○○".
- 같은 미니미는 12초 안에 다시 말하지 않아요 (도배 방지).
- 날짜·역할·비용 같은 약속은 미니미가 대신하지 않아요.

## 안 될 때

| 증상 | 확인할 것 |
| --- | --- |
| 미니미가 말을 안 함 | 자리 비움을 켰는지, 12초가 지났는지. 근거 없는 주제면 일부러 말하지 않음 |
| 휴대폰에서 2차 검증 버튼이 안 보임 | 내 말풍선을 한 번 누르기. 결정으로 기록된 말은 '2차 검증'만 보임 |
| '예시 보고서 넣기'가 없음 | '시연용 시나리오로 채우기'로 만든 방에서만 보임 |
| 이름이 예전 이름(민수·지현·하은) | 최신 코드를 받고 서버를 다시 켜면 시연 방이 새 이름으로 바뀜. 새 방을 만들어도 됨 |
| 팀원이 접속을 못 함 | 같은 와이파이인지, Windows 방화벽 '허용', 주소가 localhost가 아니라 노트북 IP인지 |

> 모든 장면은 규칙 모드(모델 없이)에서 4명(노트북 1 + 휴대폰 3)이 실제로 따라 해서 확인했어요. 로컬 모델이나 API를 켜면 말투는 달라도, 누가 말하고 언제 침묵하는지는 같아요.
