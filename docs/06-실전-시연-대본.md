# 실전 시연 대본 (8분 = 슬라이드 4분 30초 + 시연 3분 + 마무리)

- 화면 공유는 **동준 노트북 하나**. 동준은 멘트만 하고, 이 화면은 **혜중이 동준 자리로 조작**한다(슬라이드 넘기기, 방 만들기, 동준 미니미 만들기, 자리 비움, 복귀). 혜중 채팅 한 줄은 혜중 자기 노트북에서.
- 종원·혜중·정민은 각자 노트북. 보고서·입장은 방을 만들 때 '시연용' 칸을 체크하면 미리 채워진다(`seed.seed_live_room`).
- 자료가 미리 있어도 모두 자리에 있는 동안엔 미니미가 말하지 않는다(대리 참석을 켠 사람 것만 말함). 그래서 자유 채팅은 안전하다.
- 휴대폰·노트북으로 보기 편한 버전(같은 순서표 + 내 줄 강조 + 복사 버튼): Claude 아티팩트 'MINIME 실전 시연 대본'.
- 이 입력 그대로 `tests/test_live_demo.py`가 실행해 확인한다. 자동 진행 속도는 `.env`의 `LIVE_AUTOPLAY_SPEED`(설명 시간 배율, 기본 1.0), 끄려면 `LIVE_AUTOPLAY=0`.

## 발표 10분 전
1. 동준 노트북(조작은 혜중): `run.bat` (서버 창 끄지 않기) → `reset_live.bat` (리허설한 `live` 방 지우기).
2. 혜중(동준 노트북): 브라우저 `http://localhost:8000/?lobby` + 슬라이드. 팀원에게 서버 창의 IP 알려 주기.
3. 종원·혜중·정민: `http://<동준 IP>:8000/?room=live` 열어 두기 (방이 아직 없다는 안내는 무시).
4. 같은 와이파이, 방화벽 허용. 리허설 때 미니미 답이 5초를 넘으면 `.env`에서 `LLM_ORDER=api` 또는 `rule`.

## 안 될 때
- '이미 있는 방 코드예요' → `live2`로 만들고 팀원에게 알리기.
- 팀원 화면에 자리가 없음 → 방 코드 칸이 live인지 보고 [불러오기].
- 미니미가 말을 안 함 → 동준 아바타가 점선인지 확인. 같은 미니미는 12초 안에 다시 말하지 않음.
- [돌아왔어요]가 안 보임 → 오른쪽 미니미의 머릿속 패널을 [×]로 닫기.
- 화면 위 [시연] 버튼은 누르지 않기 (실전 방에서는 실행되지 않게 막아 둠).

## 시간이 남으면 (회의 종료 전에, 위에서부터)
끝난 회의에서는 미니미가 답하지 않으므로 반드시 **회의 종료 전에** 한다.

- **A. 다른 사람 말도 2차 검증 (20초)**: 종원 `만족도 조사 응답자가 2천 명이나 되니까 이 데이터는 믿을 만해.` → 혜중(자기 노트북)이 종원 말풍선에 마우스 → [2차 검증] → "숫자가 자료와 달라요 (주장 2000명 ↔ 자료 812명 · 혜중 보고서 2문단)".
- **B. 돌아와서 답한 건 다음부터 미니미가 답함 (25초)**: 혜중(공유 화면) 내가 빠진 사이 → 미니미가 남긴 질문에 `음향 업체는 아직이야. 금요일까지 견적 3곳 받아 볼게` [답하기] → 창 닫기 → [자리 비움] 켜기 → 정민 `동준 미니미, 음향 장비 업체는 알아봤어?` → 동준 미니미 "음향 업체는 아직이에요. 금요일까지 견적 3곳 받아 볼게요 [인터뷰 2]". (자동 진행은 방마다 한 번만 돌아서 다시 켜도 대사가 나가지 않는다.)
- **C. 호출형 (20초)**: 동준 자리 비움이 켜진 상태에서 종원 [⋯] → [호출형] → `타 대학 사례 누가 알아?`(아무도 안 끼어듦) → `@동준 타 대학 사례 있어?`(동준 미니미가 보고서 2문단으로 답함).
- **D. 발언 다듬기 (10초)**: 정민 요술봉 → `공연은 1팀만 하고 나머지는 부스에 쓰자` → 다듬은 문장 확인 → [이대로 보내기].
