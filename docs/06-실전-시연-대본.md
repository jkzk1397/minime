# 실전 시연 대본: 빈 방에서 4명이 직접 (8분 = 슬라이드 4분 + 시연 4분)

진행은 **동준**(노트북 발표 화면 + 휴대폰). 종원·혜중·정민은 휴대폰. 시간은 발표 시작부터 흐르는 시계.
휴대폰으로 보기 편한 버전(사람별 탭 + 복사 버튼)은 Claude 아티팩트 'MINIME 실전 시연 대본'에 있다. 내용은 이 문서와 같다.
이 대본의 입력은 `tests/test_live_demo.py`가 그대로 실행해 확인한다 (빈 방 · 규칙 모드).

## 발표 10분 전
1. 노트북에서 `run.bat` (서버 창 끄지 않기). 창의 **팀원 접속 주소** 확인.
2. `reset_live.bat` → 리허설 때 만든 `live` 방을 지운다.
3. 노트북 브라우저: `http://localhost:8000/?lobby` 탭 + 슬라이드. 종원 휴대폰: `http://<노트북IP>:8000/?lobby` 미리 열기.
4. 같은 와이파이, Windows 방화벽 **허용**. 각자 휴대폰에 대본 페이지를 자기 이름 탭으로 열어 두기.
5. 엔진: 리허설 때 미니미 답이 5초를 넘으면 `.env`에서 `LLM_ORDER=api`(키 필요) 또는 `LLM_ORDER=rule`.

### 혜중 보고서 (빈 줄 포함 그대로)

```
작년 우리 학교 축제 예산 1억 2천만 원 중 60%인 7,200만 원이 연예인 섭외비였고, 학생 참여 프로그램에는 15%만 쓰였다.

총학생회 만족도 조사(응답 812명)에서 연예인 공연은 3.6점, 동아리·체험 부스는 4.2점이었다.

같은 조사에서 '내년 축제에 바라는 점' 1위는 학생 참여 프로그램 확대(38%)였다.

그래서 학생 참여 프로그램 예산을 늘리는 B안을 제안해야 한다고 생각한다. 다만 홍보 효과를 위해 연예인 공연은 최소 1팀은 유지해야 한다.
```

## 안 될 때
- '이미 있는 방 코드예요' → 리셋을 안 한 것. `live2`로 만들고 동준이 `live2`를 불러오기.
- 미니미가 말을 안 함 → 혜중 아바타가 점선인지 확인. 같은 미니미는 12초 안에 다시 말하지 않음.
- 미니미 답이 늦음 → 다음 대사는 답이 뜬 뒤에. 동준이 멘트로 채우기.
- 2차 검증 버튼이 안 보임 → 정민이 자기 말풍선을 한 번 톡.
- 휴대폰이 로비로 튕김 → 로비 자리 목록에서 자기 이름 누르기.
- 발표 화면의 [시연] 버튼은 누르지 않기 (실전 방에서는 실행되지 않게 막아 둠).
