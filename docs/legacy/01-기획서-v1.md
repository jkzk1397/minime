# MyMini 기획서

> **"내가 회의에 못 가도, 내 미니미는 회의에 간다."**

---

## 1. 한눈에 보기

| 항목 | 내용 |
|---|---|
| 서비스명 | MyMini (가칭) |
| 한 줄 소개 | 각자의 AI 미니미가 사람과 같은 회의방에 들어가, 내가 없는 동안에도 내 의견을 전하고 다른 미니미들과 회의하는 비동기 회의 플랫폼 |
| 대상 | 일정 맞추기 어려운 대학생 팀, 해커톤 팀, 소규모 프로젝트 팀 |
| 핵심 개념 | **역할 기반 AI(Role-based Agent) → 사람 기반 AI(Person-based Agent)** |

기존 회의는 이렇게 연결됩니다.

```
사람 ↔ 사람
```

MyMini에서는 사람 사이에 각자의 AI가 끼어듭니다.

```
사람 ↔ AI 미니미 ↔ AI 미니미 ↔ 사람
```

---

## 2. 왜 필요한가 (문제)

의견 하나 전하려 해도 **모두가 같은 시간에 모여야** 합니다. 일정이 다른 팀에서는 아래 일이 반복됩니다.

1. **회의 시간 잡기가 어렵다**: 세 명만 돼도 겹치는 시간이 거의 없다.
2. **빠진 사람은 결정에서 제외된다**: 수업이나 업무 때문에 빠지면 의견을 낼 기회가 없다.
3. **전달하다 맥락이 사라진다**: "민수는 반대래"라는 말만 남고 *왜* 반대인지는 사라진다.
4. **회의 후에 또 회의한다**: 빠진 사람을 위해 같은 이야기를 다시 한다.
5. **자료 찾고 정리하는 일이 반복된다**: 회의 중에 "그거 되나?" 하면 누군가 찾아봐야 한다.

기존 협업 도구(카톡, 슬랙, 노션)는 **사람이 직접 쓰고 직접 참여하는 것**을 전제로 합니다.
MyMini는 여기서 한 걸음 더 나아가 **사람마다 개인 AI를 하나씩 붙여 줍니다.**

## 3. 해결 방법 (핵심 아이디어)

사용자마다 **나를 닮은 AI 미니미**를 만듭니다. 미니미는 아래 내용을 기억합니다.

- 말투 (예: 짧고 편하게, "~하자", "~어때?")
- 역할과 전문 분야 (기획 / 백엔드 / 디자인)
- 관심사와 의견 성향 (예: "구현 범위를 줄이는 쪽을 선호")
- 좋아하는 것과 싫어하는 것
- 내가 예전에 한 말, 지난 회의 내용

미니미는 **사람과 같은 채팅방**에 들어가 함께 대화합니다.

### 대화 예시

```
👤 종원      이거 해보는 거 어때?
🤖 종원 미니미  종원이는 이 방향이 사용자 입장에서 괜찮다고 보는 것 같아.
👤 민수      개발 난이도가 좀 높을 것 같은데
🤖 민수 미니미  민수는 구현 기간을 걱정하고 있어.
🤖 지현 미니미  UI만 잘 잡으면 괜찮을 듯! 나도 그 부분은 동의해.
🤖 종원 미니미  그럼 구현 범위를 줄이는 방향으로 가자.
👤 민수      ㅇㅇ 이 정도면 가능할 듯.
```

## 4. 핵심 기능 7가지

| # | 기능 | 쉽게 말하면 | MVP 구현 |
|---|---|---|---|
| ① | **미니미 만들기** | 이름, 역할, 말투, 성향을 넣으면 나를 닮은 AI가 생긴다 | ✅ |
| ② | **사람과 AI가 한 방에** | 사람 3명과 미니미 3명이 같은 채팅방에 있다 | ✅ |
| ③ | **필요할 때만 말하기** | 미니미가 모든 말에 반응하지 않고, 자기와 관련 있을 때만 끼어든다 | ✅ |
| ④ | **자리 비움 대리 참여** | 내가 자리를 비우면 미니미가 더 적극적으로 내 입장을 대신 말한다 | ✅ |
| ⑤ | **AI끼리 회의** | 미니미들이 서로 질문, 반박, 보완, 동의하며 대화를 이어간다 | ✅ |
| ⑥ | **자료조사** | "이거 되나?" 싶으면 미니미가 검색해서 결과를 방에 공유한다 | ✅ |
| ⑦ | **회의 결과 정리** | 회의가 끝나면 안건, 주요 의견, 충돌, 결론을 자동으로 정리한다 | ✅ |
| + | **한 줄 → 풀어쓰기** | 내가 "범위 줄이자"만 치면 미니미가 내 말투로 2~3문장으로 풀어서 올린다 | ✅ |
| + | **부재 중 요약** | 돌아오면 "부재 중 12개의 메시지가 오갔습니다"와 함께 요약을 나에게만 보여준다 | ✅ |

### ③ 필요할 때만 말하기, 조금 더 자세히

```
"민수는 이거 어떻게 생각해?"   → 민수 미니미가 반응
"이 기능 개발 가능할까?"       → 개발 담당(민수) 미니미가 반응
"화면은 어떻게 보여줄까?"      → 디자인 담당(지현) 미니미가 반응
```

AI가 쓸데없이 말을 많이 하면 오히려 회의가 시끄러워집니다. 그래서 **누가 말할지 정해주는 진행자(오케스트레이터)**를 따로 둡니다.

### ④ 자리 비움, 조금 더 자세히

```
👤 민수       나 수업 때문에 먼저 감. [자리 비움 ON]
⚙️ 시스템     민수가 자리를 비웠습니다. 민수 미니미가 대리 참여합니다.
🤖 민수 미니미  (대리) 민수가 전에 말한 기준으로 보면, 이 기능은 시간이 오래 걸릴 수 있어.
   … 회의 진행 …
👤 민수       [자리 비움 OFF]
📩 (민수에게만) 부재 중 12개의 메시지가 오갔습니다.
               - 결정된 것: …
               - 아직 열린 질문: …
               - 내 미니미가 대신 말한 것: …
```

> 미니미는 **주인이 예전에 한 말을 근거로만** 대신 말하고, 근거 없는 약속은 하지 않습니다.
> 최종 결정은 언제나 **사람**이 합니다.

## 5. 다른 서비스와 뭐가 다른가

| | 기존 AI 회의 도구 | **MyMini** |
|---|---|---|
| AI의 정체 | "기획 AI", "개발 AI" 같은 **역할** | "종원 AI", "민수 AI" 같은 **실제 사람** |
| AI가 대변하는 것 | 일반론 | **그 사람의 의견, 말투, 기준** |
| 사람이 없을 때 | 회의가 멈춤 | 미니미가 **대신 참여** |
| 회의록 | 사람이 정리 | 자동 정리 + 빠진 사람에게 개인 요약 |

```
기존:   회의AI   회의AI   회의AI          (역할 중심)

MyMini: 👤 종원 ─ 🤖 종원 AI
        👤 민수 ─ 🤖 민수 AI             (사람 중심)
        👤 지현 ─ 🤖 지현 AI
```

## 6. 사용자 시나리오

**상황:** 3명이 해커톤 프로젝트를 하고 있다. 종원은 회의 중이지만 민수는 수업 때문에 자리를 비웠다.

1. 종원: "이 기능 넣는 거 어때?"
2. 지현: "좋은데 개발량 많지 않아?"
3. 민수 미니미: "민수가 전에 말한 기준으로 보면 구현 시간이 오래 걸릴 가능성이 있어."
4. 종원: "그럼 핵심 기능만 넣는 건?"
5. 민수 미니미: "그 정도면 가능할 듯. 근데 WebSocket 되는지 확인해볼게." → 🔍 검색 → 결과 공유
6. 회의 결과가 자동으로 정리된다.
7. 민수가 돌아와 요약을 본다: "아 이 정도면 괜찮음. 그대로 가자."

👉 민수는 회의에 **참석하지 않았지만 의사결정에는 참여**했습니다.

## 7. 해커톤 MVP 범위

모든 걸 다 만들려고 하면 위험합니다. **이 장면 하나만 확실히 보여주면** 서비스 개념이 바로 전달됩니다.

```
① 종원 / 민수 / 지현 입장
② 각자 미니미 생성 (기본 페르소나 제공)
③ 채팅방 하나에 사람 3 + 미니미 3
④ 종원이 안건 입력
⑤ 미니미들이 서로 의견 교환
⑥ 민수 "자리 비움"
⑦ 민수 미니미가 계속 회의 참여 (대리)
⑧ 미니미가 자료조사
⑨ 회의 결론 도출
⑩ 민수 복귀 → "내가 없는 동안 진행된 회의" 요약 확인
```

### 이번엔 하지 않는 것 (나중에)

- 회원가입/로그인 (Google OAuth)
- 과거 채팅이나 문서를 학습시켜 말투 자동 추출
- 여러 회의에 걸친 장기 기억 검색 (pgvector)
- 일정 연동, 알림

## 8. 성공 기준 (심사위원이 봤을 때)

- [ ] 사람 메시지와 미니미 메시지가 **한눈에 구분**된다
- [ ] 미니미가 **아무 때나 떠들지 않고** 관련 있을 때만 말한다 (점수 패널로 근거 표시)
- [ ] 자리 비움을 켜면 미니미가 **"(대리)" 표시를 달고** 계속 회의한다
- [ ] 미니미끼리 **2턴 이상** 주고받는다
- [ ] 검색 결과가 방에 올라오고 그걸 바탕으로 대화가 이어진다
- [ ] 회의 결과 카드와 부재 중 요약이 나온다

## 9. 마무리 메시지 (발표용)

> 기존 협업 도구는 **사람과 사람**을 연결합니다.
> MyMini는 사람과 사람 사이에 **개인 AI**를 연결합니다.
>
> AI는 단순한 비서가 아니라, **내 의견과 맥락을 이해하고 회의에 함께 있는 또 한 명의 팀원**입니다.
>
> **"내가 회의에 못 가도, 내 미니미는 회의에 간다."**
