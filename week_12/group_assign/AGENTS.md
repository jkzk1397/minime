# 12주차 과제 산출물 수정 지침

이 폴더의 과제 산출물을 수정하기 전에 [과제 진행 및 안내 기준](과제_진행_및_안내_기준.md)을 읽고 사용자의 최신 요청과 대조한다.

- STEP 1의 여섯 항목과 각 프롬프트의 다섯 필수 항목을 확인한다.
- 기능 변경 요청이 없으면 기존 개선과 실행 코드를 유지한다.
- HTML 셀별 복사 원문, HTML 전체 미리보기, ipynb를 함께 갱신하고 내용 일치를 확인한다.
- 과제 기준·기록 형식·실행 검증 범위는 기준 문서에 따라 확인한다.
- 실제 사용 이력·실행 결과와 작성용 요청문을 구분하고 수행하지 않은 개인 활동을 사실로 적지 않는다.
